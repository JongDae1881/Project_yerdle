## 터미널에서 명령 실행하기

`brew install wget`을 입력하면 [[02 · Terminal.app|Terminal.app]]이 입력을 [[03 · 셸과 zsh|zsh]]에 전달한다. zsh는 명령을 해석하고 [[04 · PATH|PATH]]에서 `brew`를 찾아 실행한다. `brew`는 `install wget`을 인자로 받아 설치를 처리한다. 터미널, 셸, `brew`는 모두 [[01 · macOS|macOS]] 위에서 실행된다.

## 꼬들 프로젝트에 적용

| 도구 | 역할 |
| --- | --- |
| Git | 소스 코드의 변경 이력을 기록하고 공유한다. |
| JDK | Java 소스의 컴파일과 Java 프로그램 실행에 필요한 도구를 제공한다. |
| Maven | Java 프로젝트의 의존성 관리, 테스트, 패키징을 수행한다. |
| Node.js | 브라우저 밖에서 JavaScript를 실행하며 프런트엔드 개발 도구를 구동할 수 있다. |

```sh
brew install maven
mvn package
```

첫 번째 명령은 **Maven이라는 개발 도구를 설치**한다. 두 번째 명령은 Maven 프로젝트의 `pom.xml`이 있는 디렉터리에서 실행하며, **그 프로젝트를 빌드하고 패키징**한다. 산출물은 프로젝트 설정에 따라 달라진다. 예를 들어 JAR 프로젝트라면 기본적으로 `target/` 아래에 JAR 파일이 생성된다.

[Maven 빌드 수명 주기](https://maven.apache.org/guides/introduction/introduction-to-the-lifecycle.html)
