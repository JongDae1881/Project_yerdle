> - [[04 · Homebrew의 패키지 설치 방식 비교|Homebrew의 패키지 설치 방식 비교]] — 두 경로의 차이

소스 빌드는 프로그램의 소스 코드를 가져와 실행하거나 배포할 수 있는 결과물을 만드는 과정이다. C로 작성된 `wget`을 컴파일하는 경우 흐름은 다음과 같다.

1. **소스와 의존성을 준비한다.** 소스를 받고, 빌드 도구와 필요한 라이브러리를 준비한다.
2. **컴파일한다.** Clang 같은 컴파일러가 C 소스에서 목적 파일을 생성한다.
3. **링킹한다.** 링커가 목적 파일과 필요한 라이브러리를 연결해 실행 파일을 만든다.
4. **설치한다.** 만들어진 실행 파일과 관련 파일을 설치 위치에 배치한다.

대표적인 macOS 빌드 도구와 SDK는 [[02 · Xcode Command Line Tools|Xcode Command Line Tools]]에 포함된다. 필요한 도구는 프로젝트마다 다르다. 예를 들어 Maven을 소스에서 빌드할 때는 Maven 프로젝트가 요구하는 JDK가 필요하다.

Homebrew에서 `brew install --build-from-source wget`을 실행하면 [[01 · Homebrew Formula|wget Formula]]의 절차로 내 Mac에서 `wget`을 빌드한다. 의존 패키지는 호환되는 [[02 · Homebrew Bottle|Bottle]]로 설치될 수 있다. [Homebrew 명령 설명서](https://docs.brew.sh/Manpage)
